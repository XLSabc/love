# 一封写给你的信 · A Letter For You

一个可以直接打开、慢慢读完的表白网站。以“私人出版物”为概念，做成八个章节：序、瞬间、星图、理由、信、以后、诗、答案。

不是套模板的表白页——它有开场封缄、心动时间线、可互动的星图、八条喜欢你的理由、火漆下的秘密、三封未寄出的短信、四季卡片、可以打勾的“以后清单”、一首藏头诗、页首的金色阅读进度、一页私人版本说明、环境音，以及一个在回答“好”之后才会出现的纪念卡。

---

## 怎么打开

最简单的方式：双击 `index.html`。

如果浏览器不允许本地文件加载字体，或者你想在手机上预览，可以在文件夹里打开终端，运行：

```bash
python -m http.server 5178
```

然后访问：

```
http://127.0.0.1:5178
```

> 不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 先改这几处，它就会变成你的信

打开 `js/config.js`，只改引号里的内容：

```js
window.LOVE_CONFIG = {
  recipient: "你",                    // 收信人
  sender: "一个喜欢你的人",            // 落款
  date: "2026.10.20",                // 页面日期
  dateISO: "2026-10-20",             // 下载纪念卡的文件名日期
  pageTitle: "致你｜一封写给你的信",     // 浏览器标签页
  stars: [ ... ]                     // 星图里的七颗星
};
```

星图里的每一颗星都可以换成你们真正的时刻：

```js
{
  title: "初见",
  text: "那天你说了什么，我其实已经记不清了。只记得你抬头的时候，世界忽然安静了一下。"
}
```

## 换一种颜色

打开 `css/style.css`，最上面的 `:root` 就是整套视觉的调色盘：

```css
--paper: #f2ede3;     /* 纸张底色 */
--ink: #1c1a17;       /* 主文字 */
--red: #a33a2a;       /* 印章红 */
--gold: #a88455;      /* 金棕 */
--night: #11140f;     /* 星图与结尾的夜色 */
```

只改这几个值，整站的颜色气质就会跟着变。

## 已经为你做好的细节

- **开场封缄**：点击朱砂印章，像揭开一张信纸一样进入。
- **阅读进度**：页首一条极细的金线，随着阅读缓慢向右延伸。
- **心动时间线**：从“还没遇见你”一路走到“此刻”，滚动时红线会慢慢长出来。
- **星图**：移动光标或轻触星星，会点亮对应的注释。
- **手风琴式理由**：八条理由，一次展开一个，不会把页面堆得太满。
- **火漆秘密**：信纸右下角的火漆可以点开，下面压着一句没敢写进信里的话。
- **三封没有寄出的短信**：三张折纸卡片，可以逐张展开，像翻开旧草稿箱。
- **四季卡片**：春、夏、秋、冬四张纸笺，写着想和你一起过的以后。
- **“以后”清单**：点一下会盖上红色对勾，并记住你的选择（浏览器本地存储）。
- **藏头诗**：四列竖排小诗，点“读出藏头”，第一字会亮起来。
- **版本页**：页脚像书的版权页一样，写着版本、字体与制作信息。
- **环境音**：右上角 `SOUND`，用 Web Audio 现场合成的极轻氛围声，不加载音频文件。
- **回答彩蛋**：点“好，一起写”后，会有一场花瓣和一张可以下载的纪念卡。
- **纪念卡**：1080 × 1350 的 PNG，包含日期、名字和一句落款。
- **响应式**：手机、平板、桌面都有单独调整；主按钮带很轻的磁吸跟随。
- **减少动态效果**：尊重系统的 `prefers-reduced-motion` 设置。
- **隐私**：没有后端、没有统计、没有外部图片。所有内容都在本地；页面也默认设置了 `noindex` 和 `robots.txt`，不会被搜索引擎收录。

## 藏在页面里的四十个彩蛋

**第一层：点一下就会遇见**

1. **火漆之下**：信纸右下角的火漆印章，点开后会露出一句话。
2. **第八颗星**：把星图里的七颗星都点亮，注释卡底部会多出一行小字。点击它，会找到那颗不在图上的星。
3. **版本附记**：页脚 `EDITION` 旁边的小星可以点击，展开一段没有放在正文里的 P.S.
4. **太阳之下**：点首屏插画里那颗巨大的红色太阳，会浮出一行没有标在画上的字。
5. **信纸脚注**：信里“不催你，也不收回”后面的小圆圈 `†`，是一个可以点开的脚注。
6. **月亮之下**：在“你说晚安之后”的卡片里，点一下那颗月亮。
7. **你在这里**：首屏插画右侧的竖排小字，点一下会变成“一直是你”。
8. **未完待续**：时间线底部的 `TO BE CONTINUED` 可以点，会续写一行“下一页”。
9. **第四封短信**：把三张未寄出的短信都打开，草稿箱底部会多一行字。
10. **第七件事**：把“以后清单”的六件事全部打勾。
11. **诗页印章**：诗页右下角的“藏”可以点开，露出一句话。
12. **最后一颗星**：结尾“谢谢你读到这里”后面的小星，点开是一个没有说出口的答案。
13. **第 00 章**：在电脑上按数字键 `0`，或双击页眉 / 页脚的 `A/L`，会打开一封原本不打算寄出的短信。
14. **邮戳之下**：点信纸右上角的“私藏”邮戳。
15. **信纸日期**：点落款下面的日期，会看到写信那晚的另一个细节。
16. **第九条理由**：把“喜欢你的理由”八条全部展开一次。
17. **WHY 之后**：点理由页左侧巨大的 `WHY`，会多出一行真正的理由。
18. **第五季**：依次点一下春、夏、秋、冬四张卡片。
19. **观测对象**：点星图左上角的赤经 / 赤纬坐标。
20. **许愿星**：点首屏插画左上角那颗很小的红星。
21. **后记**：点结尾右下角的 `OR THE BEGINNING`，会打开一整页没有放在正文里的后记。

**第二层：不用点击，也会发生**

22. **键盘里的 love**：在电脑上直接敲出 `love`，页面底部会短暂出现一张小纸条。
23. **标签页**：切换到别的标签再回来，标题会悄悄变两次。
24. **凌晨**：在 23:00–04:00 之间打开，页脚会多一行字。
25. **控制台**：打开浏览器开发者工具的控制台，会看到一句写给好奇的人的话。
26. **停留**：在同一页停留 45 秒不动，底部会浮出一句“不用急着翻页”。
27. **带走一句**：在信、诗或结尾里选中一段较长的文字并复制，会收到一张小纸条。

**这一轮新增的 13 个**

28. **P.P.S.**：点信末的 `P.S.`，会多出一句原本没打算写的话。
29. **落款**：点“—— 一个喜欢你的人”这行签名。
30. **页码**：点信纸顶部的 `PAGE 01 / 01`，页码会变成 `PAGE 01 / ∞`。
31. **问号背面**：点最后那句“把以后写成故事吗”的 `？`。
32. **藏头里的四个字**：读出藏头后，点“我喜欢你”。
33. **再读一行**：藏头答案下面还有一个小按钮，点开是一句没有藏进诗里的情话。
34. **阅读时间**：点首屏底部的“慢慢读，不着急”。
35. **Reason 08**：点理由页侧栏的 `08 / REASONS`。
36. **画的背面**：点首屏插画下方 `the reason of all things`。
37. **05:20**：如果你刚好在 05:20 打开页面，页脚会出现一行字。
38. **10.20**：在 10 月 20 日打开，页脚会多一行“信上写的日子”。
39. **回来的人**：第二次打开这个页面时，页脚会认出你。
40. **Konami**：依次按 `↑ ↑ ↓ ↓ ← → ← → B A`，会下一场很轻的花瓣雨。

## 关于字体

页面使用了两套 SIL Open Font License 字体：

- **Noto Serif SC**：中文正文与标题
- **Cormorant Garamond**：英文与数字

字体已经做了本地子集化，并以 data URI 的形式内嵌在 `css/fonts.css` 里，所以即使直接双击 `index.html`、完全不联网，也能保持现在的样子。`assets/fonts/` 里的 WOFF2 是同一份子集的源文件备份，页面不会再次请求它们；如果要更换字体，需要修改 `css/fonts.css` 中的 `@font-face`。

如果修改文案时加入了字体子集里没有的生僻字，那个字会自动回退到系统宋体；整体仍然可读，只是字形会略有不同。

## 发布到网上

把整个文件夹原样上传到 Netlify、Vercel、Cloudflare Pages 或 GitHub Pages 就可以。入口文件是 `index.html`，无需构建命令。

如果这是要发给某个人的链接，建议把 `js/config.js` 里的名字和日期先改好，再把链接发出去。

---

## 发出前，检查这 5 件事

1. `js/config.js` 里的收信人、落款、日期都改好了。
2. “三个瞬间”“心动时间线”和“八个理由”里，至少有一半是你们真实发生过的事。
3. 在手机上看过一遍：开场、星图、信、藏头诗和最后的问题都能正常显示。
4. 点一次“读出藏头”、展开一张未寄出的短信，再点一次“好，一起写”，确认纪念卡可以下载。
5. 如果你在同一台设备上测试过，发出前用无痕窗口再打开一次，确保对方看到的是干净的初始状态。
