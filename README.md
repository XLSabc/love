# 一封写给你的信 · A Letter For You

一个可以直接打开、慢慢读完的表白网站。以“私人出版物”为概念，做成八个章节：序、瞬间、星图、理由、信、以后、诗、答案。

不是套模板的表白页——它有开场封缄、心动时间线、可互动的星图、八条喜欢你的理由、火漆下的秘密、三封未寄出的短信、四季卡片、可以打勾的“以后清单”、一首藏头诗、环境音，以及一个在回答“好”之后才会出现的纪念卡。

---

## 怎么打开

最简单的方式：双击 `index.html`。

如果浏览器不允许本地文件加载字体，或者你想在手机上预览，可以在文件夹里打开终端，运行：

```bash
python -m http.server 5178
```

然后访问：

```
http://127.0.0.1:5178
```

> 不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 先改这几处，它就会变成你的信

打开 `js/config.js`，只改引号里的内容：

```js
window.LOVE_CONFIG = {
  recipient: "你",                    // 收信人
  sender: "一个喜欢你的人",            // 落款
  date: "2026.10.20",                // 页面日期
  dateISO: "2026-10-20",             // 下载纪念卡的文件名日期
  pageTitle: "致你｜一封写给你的信",     // 浏览器标签页
  stars: [ ... ]                     // 星图里的七颗星
};
```

星图里的每一颗星都可以换成你们真正的时刻：

```js
{
  title: "初见",
  text: "那天你说了什么，我其实已经记不清了。只记得你抬头的时候，世界忽然安静了一下。"
}
```

## 换一种颜色

打开 `css/style.css`，最上面的 `:root` 就是整套视觉的调色盘：

```css
--paper: #f2ede3;     /* 纸张底色 */
--ink: #1c1a17;       /* 主文字 */
--red: #a33a2a;       /* 印章红 */
--gold: #a88455;      /* 金棕 */
--night: #11140f;     /* 星图与结尾的夜色 */
```

只改这几个值，整站的颜色气质就会跟着变。

## 已经为你做好的细节

- **开场封缄**：点击朱砂印章，像揭开一张信纸一样进入。
- **心动时间线**：从“还没遇见你”一路走到“此刻”，滚动时红线会慢慢长出来。
- **星图**：移动光标或轻触星星，会点亮对应的注释。
- **手风琴式理由**：八条理由，一次展开一个，不会把页面堆得太满。
- **火漆秘密**：信纸右下角的火漆可以点开，下面压着一句没敢写进信里的话。
- **三封没有寄出的短信**：三张折纸卡片，可以逐张展开，像翻开旧草稿箱。
- **四季卡片**：春、夏、秋、冬四张纸笺，写着想和你一起过的以后。
- **“以后”清单**：点一下会盖上红色对勾，并记住你的选择（浏览器本地存储）。
- **藏头诗**：四列竖排小诗，点“读出藏头”，第一字会亮起来。
- **环境音**：右上角 `SOUND`，用 Web Audio 现场合成的极轻氛围声，不加载音频文件。
- **回答彩蛋**：点“好，一起写”后，会有一场花瓣和一张可以下载的纪念卡。
- **纪念卡**：1080 × 1350 的 PNG，包含日期、名字和一句落款。
- **响应式**：手机、平板、桌面都有单独调整。
- **减少动态效果**：尊重系统的 `prefers-reduced-motion` 设置。
- **隐私**：没有后端、没有统计、没有外部图片。所有内容都在本地；页面也默认设置了 `noindex` 和 `robots.txt`，不会被搜索引擎收录。

## 额外的小开关

- 想跳过开场，在网址后加 `?skipIntro=1`。
- 想强制重新看开场，加 `?intro=1`。
- 同一个浏览器标签页里打开过一次后，再次刷新会直接进入正文。

## 关于字体

页面使用了两套 SIL Open Font License 字体：

- **Noto Serif SC**：中文正文与标题
- **Cormorant Garamond**：英文与数字

字体已经做了本地子集化，并以 data URI 的形式内嵌在 `css/fonts.css` 里，所以即使直接双击 `index.html`、完全不联网，也能保持现在的样子。`assets/fonts/` 里的 WOFF2 是同一份子集的源文件备份，页面不会再次请求它们；如果要更换字体，需要修改 `css/fonts.css` 中的 `@font-face`。

如果修改文案时加入了字体子集里没有的生僻字，那个字会自动回退到系统宋体；整体仍然可读，只是字形会略有不同。

## 发布到网上

把整个文件夹原样上传到 Netlify、Vercel、Cloudflare Pages 或 GitHub Pages 就可以。入口文件是 `index.html`，无需构建命令。

如果这是要发给某个人的链接，建议把 `js/config.js` 里的名字和日期先改好，再把链接发出去。

---

## 发出前，检查这 5 件事

1. `js/config.js` 里的收信人、落款、日期都改好了。
2. “三个瞬间”“心动时间线”和“八个理由”里，至少有一半是你们真实发生过的事。
3. 在手机上看过一遍：开场、星图、信、藏头诗和最后的问题都能正常显示。
4. 点一次“读出藏头”、展开一张未寄出的短信，再点一次“好，一起写”，确认纪念卡可以下载。
5. 如果你在同一台设备上测试过，发出前用无痕窗口再打开一次，确保对方看到的是干净的初始状态。
